## 試着画面（2Dアバターの作り直し）

- `outfit` と `/try-on` を共通ヘッダーから切り替える構成。コーデと配色は共通のPiniaストアで保持。
- 旧実装の「肩・腰・股・膝は固定、足首だけ頭身依存」を廃止し、頭 / 首 / 胴 / 太もも / ふくらはぎ / 足の6セグメントを毎回組み直すリグに置き換えた。合計は必ず頭身数に正規化され、頭を大きくしてもスネだけが伸びない。足裏は常に同じ接地線に乗る。
- FKの腕・脚（DragonBones / Spine系）、レイヤー合成（DiceBear）、パーツ・色の選択（Picrew）を参考に、`avatarRig.ts` / `avatarShapes.ts` / `garmentShapes.ts` を分離。
- 5頭身（デフォルメ）は、つくみず作品の脱力した半まぶたのじと目・小さな口・斜線の頬・丸い頭・不揃いな毛先を参考にした独自SVG。既存キャラクターの模写はしない。
- アバターパネルで髪型6種、髪色7種、肌色6種、瞳色6種、目5種、眉4種、口5種、頬4種、ウインク3種、体型3種、ポーズ5種を変更でき、PiniaとlocalStorageに保持。
- 頭身は5/7/9のボタンと4〜10のスライダー。中央の着せ替え/イラスト切り替え、背景色、表示倍率、素体のみ、頭身ガイド、配色反映を操作できる。
- 頭・バッグ・アクセサリーもSVGで描画。端末内で生成したPNGは、頭身・体型・ポーズから計算した部位の配置枠（`garmentImagePlacements`）に収める。
- フロントエンド23テスト: リグの接地線・関節順・頭1単位の増分、5/7/9頭身で胴の輪郭が3種類に組み直されること、アバターの肌・髪・表情の反映、衣装と配色の即時反映、生成PNGの5/7/9頭身フィット、42衣装×5/7/9頭身で不正座標がないこと、イラスト用プロンプトとファイル名。
- ヘッドレスChrome（1440×1200）で5/7/9/10頭身、丸体型＋ばんざい、メガネ・リュック・フープピアス・ロングブーツを表示し、破綻しないことを確認。
- ヘッドレスChromeの実ビューポート390pxで横スクロールが発生しないこと、アバターパネルがステージと重ならないことを確認。
