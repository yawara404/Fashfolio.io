## 1. ビジュアルリファレンス＆デザイン哲学（最重要）

目指すのは「衣装が100%主役として引き立つ、無機質だが愛らしい無彩色の2D素体」です。

1. **丸い頬と柔らかな表情のオリジナルアニメキャラクター**:
   - **輪郭**: お餅のように下頬がふっくらした丸顔（極端な尖り顎は厳禁）。ストンとしたなで肩。
   - **目元**: 水平に近い上まぶたのジト目。縦長の大きな黒目がまぶたに隠れる、眠たげで柔らかい表情。瞳は単色で塗り、ハイライトは入れない。
   - **鼻・口**: 鼻はごく小さな点。口は小さく柔らかな笑顔。
   - **チーク**: 素朴な斜線ストローク（`///`）。丸いグラデーションチークは不可。

2. **Picrew「ふわふわ鱈メーカー」の毛束ニュアンス（※ローポリ絶対厳禁）**:
   - 直線（`L`）の多用によるカクカクしたポリゴン化は絶対に避けること。
   - すべての髪束・毛先・輪郭は、滑らかな三次ベジェ曲線（`C`）および二次ベジェ曲線（`Q`）で描く。
   - 頭の丸みに優しく沿う、とろけるようなふんわりした前髪とサイドのほつれ束。

3. **COEIROINK（コエイロインク）デフォルトキャラクターのような無彩色パレット**:
   - 人間の肌色（オレンジベージュ）や派手な髪色は使用しない。
   - **素体肌**: 純白 `#FFFFFF`（影色：極薄いペールグレー `#EAE8F2`）。
   - **髪**: 淡いスレートグレー `#E2E4EE`（ハイライト：`#F8F9FC`、影：`#C9CCD9`）。
   - **主線（Line）**: 真っ黒ではなく、インクグレー `#524C60`（ストローク端は `round`）。
   - **瞳**: ディープスレート `#353140` の単色。白い点、グレーの反射、グラデーション、光沢は入れない。白目と髪の明部は別扱い。
   - **少年／少女の切り替え**:
     - **少女**: ふんわりした前髪 ＋ 左右のサイドほつれ束（side lock）。
     - **少年**: 軽めの無造作ショート ＋ すっきりした襟足。目元と眉は柔らかい表情。

## 2. 美術解剖学に基づく頭身スケーリング（骨格計算）

スライダまたはボタンで **5頭身（デフォルメ）、6頭身（ナチュラル）、7頭身（スタンダード）** が切り替わります。
単なる全体の `scaleY` やスネだけを伸ばす実装は破綻するため、以下の正規化骨格モデルを採用してください。

- **基準骨格（Canonical Body）**:
  首〜足首までの基準長を `B0 = 3.80` と定義。
  ```typescript
  const B0 = 3.8;
  const u = computed(() => 612 / props.heads); // 1頭身のピクセル単位
  const oy = 42; // 頭頂のY原点
  const bodyOrigin = computed(() => oy + 1.15 * u.value); // 首の付け根Y
  const sy = computed(() => (props.heads - 1.15) / B0); // 縦スケール
  const sx = computed(() => 1 + (sy.value - 1) * 0.42); // 頭身に応じた横幅の連動補正
  const bodyStroke = computed(() => 0.015 / Math.sqrt(sx.value * sy.value));
  ```
- **配置連動**:
  - 頭部: `transform="translate(240 ${oy}) scale(${u})"`
  - 胴体・脚: `transform="translate(240 ${bodyOrigin}) scale(${u * sx} ${u * sy})"`
  - 衣装（トップス・ボトムス・靴・バッグ）は胴体と同じ正規化座標系（0 .. 3.80）に配置され、頭身を変えても肩・腰・股下・膝・足首に狂いなく追従すること。

## 3. アンチパターン（絶対にやってはいけないこと）

- ❌ 直線の連続で描かれたローポリ・幾何学図形のような髪型や輪郭。
- ❌ オレンジ系の肌色やカラフルな髪色（試着する服の色を邪魔するため、素体は徹底して無彩色・薄灰・純白にする）。
- ❌ 過剰なアバター着せ替え機能（肌色変更や目の色変更など）の埋め込み（素体はあくまでニュートラルなマネキン）。
